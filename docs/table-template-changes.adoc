= Changes Between table-template.red Version 0.093 and Version 0.107

== Overview

This document details all changes between the older version: 0.093 (3820 lines) and the newer version: 0.107(6554 lines). The newer version has significantly expanded functionality with approximately 2734 additional lines of code.

== Major Additions

=== New Functions

==== Video/Display Decor Management
* `remove-vid-col-decor` - Removes video column decorations
* `clear-vid-decor` - Clears all video decorations from a face

==== Column Management Enhancements
* `place-pre-buit-col` - Places pre-built columns with overlay configuration
* `make-overlay-config` - Creates overlay configuration for pre-built columns
* `step-num-keys` - Steps up or down numeric keys in a map based on comparator
* `step-item-vals` - Steps item values in a series based on comparator

==== Virtual Column Support
* Enhanced virtual column handling with code and VID overlays
* `set-virt-col-code` - Sets virtual column code
* `set-virt-col-vid` - Sets virtual column VID

==== Overlay System
* New overlay configuration system for cells
* Support for code-repeating and vid-repeating overlays
* Pre-built overlay types including:
  * `cell-checkbox-for-row-selection`
  * `cell-button`
  * `cell-code-example`
  * `data-checkbox-for-logic`
  * `data-drop-list`

==== File Format Support
* `open-red-type-table` - Enhanced file opening with support for `.redtbl` format
* `save-redtbl` - Saves tables in binary `.redtbl` format
* `recast-none` - Converts 'none words to #(none) for proper serialization

==== Multi-line Editor
* `multi-line-editor` - New multi-line cell editing capability
* `advanced-cell-edit` - Advanced cell editing functionality

==== Update Functions
* `update-vid-cell` - Updates VID cell values

=== New Menu Options

==== Column Operations
* `insert-pre-built-col` - Insert pre-built column
* `append-pre-built-col` - Append pre-built column
* `set-virt-col-code` - Set virtual column code

* `set-col-read-write` - Set column to read-write

== Migration Notes

When migrating from version 0.93 to the newer version:

1. **Selection Field**: All code using `face/selected` should be updated to `face/cells-selected`
2. **File Opening**: The `open-red-table` function has been renamed to `open-red-type-table`
3. **New File Format**: Consider using `.redtbl` format for better performance and feature support
4. **State Files**: State files now include additional fields; old state files may need migration
5. **Virtual Columns**: New virtual column system requires understanding of VID overlays and code overlays
6. **Read-Only Support**: New read-only row/column functionality available
7. **Defaults**: Default values are now stored separately in binary format
